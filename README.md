# Thauma Energistics

*Because the digital age could use some magic!*

A bridge between Thaumaturge and Applied Energistics 2 for Minecraft 26.1.2 (NeoForge). It is a port of Thaumic Energistics.

## Requirements

- Minecraft 26.1.2 with NeoForge 26.1.2 or newer
- Thaumaturge 1.1.0
- Applied Energistics 2 26.1

Optional: ExtendedAE, Advanced AE, AE2WTLib (adds the wireless terminals to the universal wireless terminal), JEI (drag essentia into bus filters) and the Terminus aspect of Thaumaturge Avaritia (unlocks the Infinity Essentia Cell).

## Features

- **Essentia in the ME network**: ME Essentia Terminal, Import Bus, Export Bus and Storage Bus.
- **Essentia storage cells** from 1k to 256k, plus a creative cell and the **Infinity Essentia Cell**, a cell with practically unlimited storage that needs the Terminus aspect.
- **ME Arcane Crafting Terminal**: arcane crafting from the network, with a wand slot, six primal crystal slots and an upgrade slot.
- **Wireless Arcane Crafting Terminal** and **Wireless Essentia Terminal**: they join the AE2WTLib universal terminal when that mod is installed.
- **Arcane Charging Upgrade**: recharges the wand stored in the arcane terminal with local vis.
- **Thaumium, Alchemical Brass and Void Metal circuits and processors** for AE2, pressed in the inscriber. The essentia storage components ask for them, each grade built upon the previous one.
- **Infusion Provider**: lets infusion pull essentia from the network.
- A Thaumonomicon research category for every part.

## Compatibility

- Thaumaturge Avaritia: its Terminus aspect works in cells, terminals and buses, and it is the key ingredient of the Infinity Essentia Cell.
- ExtendedAE: Thaumium, Alchemical Brass and Void Metal Assembler Matrix craft, pattern and speed cores, and infinite cells of arcane stone and the six primal vis crystals.
- Advanced AE: its items get essentia values in the Thaumaturge aspect index.
- AE2 Things, AE2 MEGA Things and MEGA Cells: the code is ported but excluded from the build until those mods publish a Minecraft 26.1.2 version.
- Solar Flux Reborn, Create and Mekanism have no build for Minecraft 26.1.2, so there is no compatibility with them in this version.
