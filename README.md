# Thauma Energistics

*Because the digital age could use some magic!*

A bridge between Thaumaturge and Applied Energistics 2 for Minecraft 1.21.1 (NeoForge 21.1.262). It is a port of Thaumic Energistics.

## Requirements

- Thaumaturge 1.1.0
- Applied Energistics 2 19.2.18

Optional: AE2WTLib (adds the wireless arcane terminal to the universal wireless terminal), JEI (drag essentia into bus filters), AE2 Things, AE2 MEGA Things, MEGA Cells, ExtendedAE and Advanced AE (see below).

## Features

- **Essentia in the ME network**: ME Essentia Terminal, Import Bus, Export Bus and Storage Bus.
- **Essentia storage cells** from 1k to 256k, plus a creative cell.
- **ME Arcane Crafting Terminal**: arcane crafting from the network, with a wand slot, six primal crystal slots and an upgrade slot.
- **Wireless Arcane Crafting Terminal**: opens the same GUI, and it joins the AE2WTLib universal terminal when that mod is installed.
- **Arcane Charging Upgrade**: recharges the wand stored in the arcane terminal with local vis.
- **Infusion Provider**: lets infusion pull essentia from the network.
- **Thaumium, Alchemical Brass and Void Metal circuits and processors** for AE2, pressed in the inscriber. The essentia storage components now ask for them, each grade built upon the previous one.
- **AE2 Things**: typeless essentia DISKs (1k to 256k) whose contents live on the item and can be moved between drives.
- **AE2 MEGA Things**: MEGA essentia DISKs (1M to 256M), built from MEGA Cells components.
- **MEGA Cells**: MEGA essentia storage cells (1M to 256M) with their own housing.
- **ExtendedAE**: Thaumium, Alchemical Brass and Void Metal Assembler Matrix craft, pattern and speed cores, and infinite cells of arcane stone and the six primal vis crystals.
- **Advanced AE**: its items get essentia values in the Thaumaturge aspect index.
- A Thaumonomicon research category for every part.
